# 化学互动课件：用户亲自验收清单

验收权仅属于项目所有者。本清单用于亲自操作，不代表已通过验收。请先体验科学内容及交互；发现问题先修复，再重新验证。

## 打开独立空间

1. 打开 http://127.0.0.1:5188/chemistry-lab 。侧边栏应新增“化学互动课件”，原有入口保留。
2. 应看到10张化学卡片；没有物理、生物、数学实验。
3. 点击“虚拟实验”“微观结构”“化学反应”，列表随分类变化；输入名称能搜索。
4. 在工作台切换浅色/深色，检查首页文字与卡片可读。

## 每项都亲手试一次

点击课件卡片“打开课件”。应进入以三维场景为主的沉浸页面，而非静态图片。

| 课件 | 建议操作与应看到的结果 |
| --- | --- |
| 原子结构 | 改原子序数6→7，名称由碳变氮，电子层数量为2、5；旋转/缩放观察原子核及电子运动。这里显示分层人数，不是s/p轨道式。 |
| 化学键 | 切换离子键、共价键、金属键；改变步骤，观察转移、共用或电子海。界面步骤从1起，金属键最多4步。 |
| 电解实验 | 保持步骤5，运行数秒，再调电压；可见气泡运动及H₂/O₂示意体积变化。仅水电解，不应出现错误套用同样产物的其他溶液按钮。 |
| 酸碱滴定 | 试单滴加入、自动滴加、切换盐酸/乙酸、改变浓度和指示剂；pH、颜色、体积与曲线应变化。固定酸液25mL；50mL碱液示意容量耗尽后需重置。 |
| 气体定律 | 默认300K、5L、100个示意粒子，压强约49.88kPa；改10L约24.94kPa，粒子碰撞及容器体积变化。 |
| 酸碱反应 | 提高酸浓度至0.5mol/L，观察pH仍偏酸，不应无条件变成7；Na⁺/Cl⁻不应自动宣称析出盐晶体。 |
| 晶体结构 | 切换FCC、BCC、HCP、金刚石型，切换边框/连接线并旋转。注意显示的是简化结构，不能数画面小球替代完整晶胞统计。 |
| 分子扩散 | 改温度倍率、孔径和粒子倍率，观察随机运动、穿膜和两侧计数。每次重置从初始分布重新开始，不承诺相同随机路径。 |
| 放热与吸热 | 改活化能与能量变化幅度，观察两侧运动及连续能量路径；吸热产物不能高于过渡态。温度标为示意，不是热量计结果。 |
| 元素周期表规律 | 点击三维元素方块，右侧名称/原子序数应变化；改属性和高度倍率，观察高度变化，滚轮可放大。原子序数116应显示“𫟷 · Lv”，不能是空框或需联网才能显示。 |

每项均检查：

- 鼠标拖拽旋转、滚轮缩放、右键平移能响应。
- 点击“暂停”后粒子/反应停下；点击“继续”可继续，不突然跳到另一时间段。
- “重置实验”恢复默认参数、进度和镜头；来源随机场景的随机种子不固定。
- 点击右上说明图标，阅读教学目标、理论、限制和来源，均应为中文；化学式、元素符号、单位和ScienceLab品牌保持原样是正确的。
- 参数/观察面板可收起，以获得更大画布。
- 点“全屏展示”，再退出；浏览器拒绝时应有中文提示。
- 刷新页面仍能打开当前课件，从默认状态开始。
- 返回列表后仍在工作台独立课件空间，不应跳到线上英文网站。

## 收藏与保存

1. 在首页星标收藏两项，点“我的收藏”，只显示收藏项。
2. 刷新页面，再进入收藏，仍应保留。
3. 点“导出收藏”保存JSON；可用“导入收藏”恢复。
4. 导入非法JSON或未知课件ID，应明确报错，不写入业务数据库。
5. 收藏只属于当前浏览器；清除浏览器数据会丢失，主库备份不包含收藏，请另存导出的JSON。
