## 1. 具体完成功能

### 班级

- 创建、修改名称、设置学年/年级/班级编号、切换、查看真实人数、归档及查看归档班级。
- 班名可重复，内部为稳定 UUID；下拉以学年、年级/编号和短 ID 辅助区分。
- 归档不删除班级、学生、归属或座位记录；归档班级只读，学生可转至在用班级。
- 修改学年、年级或编号时，为在班学生建立新的历史段，旧段保留、座位不变；仅改名不覆盖入班时的名称快照。

### 学生

- 单个新增、编辑姓名/可选学号/性别/入学年份/备注、按姓名或学号搜索，跨班级查询，按完整永久 ID 查询，查看当前班级。
- 永久内部 UUID 由系统生成，转班不变，不使用姓名、学号或班级作主键，同名不自动合并。
- 转班保留原归属，记录起止时间，释放旧座位并更新人数；学生归档结束当前归属、释放座位，保留档案与历史，只读查询。
- 第一版非空学号要求全实例唯一，包括归档学生；可留空。不录入身份证、电话或家庭住址。

### Excel

- 下载真实空白 .xlsx 模板，姓名/学号/性别/入学年份/备注五列；不预填样例名单。
- 先预览行号、有效/重复/错误记录，再确认写库。预览不写数据，提交重新检查数据库。
- 错误导致整批拒绝；重复可选择整批拒绝或跳过，不覆盖、不合并原档案。
- 文件内同学号/完全相同记录及系统已有学号提示重复；同名不同学号可分别创建。
- 同一二进制文件再次导入同班，返回原批次，不重复新增。保留批次哈希、结果与所创建学生 ID。
- 限 .xlsx、5MB、1000 行；校验表头、字段、文本学号、公式及压缩文件边界，拒绝宏/外链。

### 教室与详情

- 保留已验收的白灰蓝风格、深浅主题、紧凑班级栏及四项业务导航，没有恢复已删除的大标题或三块统计。
- 主页面显示真实学生/座位，不再固定展示演示学生；空实例从创建第一个班级开始。
- 1–12 行/列配置，真实分配、交换、清空，显式保存；支持拖拽及点击座位选择学生两条路径。
- 完整布局事务保存，版本冲突拒绝覆盖；重复学生、重复座位、越界、非本班/归档学生安排均拒绝。
- 点击已分配座位或名册姓名进入详情：基本资料、当前班级、座位、学年/班级历史、编辑、转班、归档与返回教室。
- 学生/班级编辑、导入等采用侧边抽屉，成功/错误有明确提示；归档须输入确认文字。
- 学生及班级关键操作保留时间、来源和前后快照，学生详情及班级操作记录可查看。
- 历次考试、错题、知识点、AI、个性化练习仅留清晰占位，不生成虚构成绩或结论。

## 5. 创建第一个班级

1. 打开班级页，点击右上“新建班级”。
2. 在侧边抽屉填写班级名称、学年、年级及编号，点击“保存班级”。
3. 看到成功提示，自动选中所建班级；教室为空座位，名册为空。
4. 可继续创建另一个班级，通过顶部下拉切换；人数来自后端当前归属统计。

## 6. 添加学生、导入和安排座位

- 滚至教室下方“班级学生”区域，点击“添加学生”，填写姓名和可选字段保存。
- 批量添加：Excel 导入 → 下载模板 → 填“学生导入”工作表 → 选文件 → 校验并预览 → 修正错误/选择重复策略 → 确认导入。
- 点击“安排座位”，设置行列；从名册拖动学生到座位，或点击座位后用选择框分配。选择已排座学生或拖到已占用位置可交换。
- 选择“空座位（清空）”释放单个座位，学生档案仍保留。
- 点击“保存座位布局”后才持久化；取消不写库。缩小布局前先清空范围外座位，错误时不会默默丢失安排。

## 7. 进入详情、转班及历史

- 普通模式点击学生座位或名册姓名，进入详情，查看永久 ID、资料、当前班级、座位与归属历史。
- 点击“编辑资料”保存修改；转班在详情选择目标在用班级，确认后旧座位释放、ID 不变、旧历史保留。
- 学生归档需输入“确认归档”，归档后保留档案和历史，可在“学生管理 → 查看已归档学生”找到。
- “返回教室”返回对应班级；班级归档也能查看，不能继续新增或排座。

## 8. 数据保存和恢复验证

1. 用模拟学生建班、排座并保存，刷新、关闭/重启，核对永久 ID、资料、归属与座位。
2. 在设置创建备份，确认文件存在且检查通过。
3. 修改一名模拟学生备注，确认已经保存。
4. 结束其他页面未保存编辑，选择此前备份，输入“恢复当前工作台”并确认。
5. 看到成功及 before-restore 副本，刷新所有页面，核对数据回到备份时点。
6. 需要撤回此次恢复，可恢复对应 before-restore 副本，较新数据及审计仍保留。

恢复作用于整个实例，不只是当前班级。只在新建验收数据上验证，不导入旧系统数据库。第一阶段 0001 的同实例备份可先在临时副本中升级后恢复，源文件保持不变；这种恢复会返回当时尚无第二阶段业务的状态。
