# 六阶段总体路线（规划，非执行授权）

本路线只作扩展方案，各阶段具体范围须由用户确认。每一阶段开发、自测、提交报告后必须停止，等待用户亲自操作。仅在用户明确说“本阶段验收通过，可以进入下一阶段”或同等授权后，才可开始下一阶段；问题先修复再重新验证。

| 阶段 | 规划范围 | 阶段边界 |
| --- | --- | --- |
| 1 项目初始化与基础界面框架 | 独立工程、四页占位、React 演示座位、主题、设置、基础 API、迁移、备份恢复 | 已由项目所有者亲自验收并批准 |
| 2 完整班级管理系统 | 多班级、学生档案、Excel 导入、归属历史、座位、审计 | 已由项目所有者亲自验收并批准 |
| 3 教材目录驱动的题库与知识点 | 学科/版本/册别/章课时、统一知识点、富文本题目、关联/导入/审核/版本/统计 | 当前唯一获准阶段；交付后停止，第四阶段未授权 |
| 4 试卷与考试记录 | 试卷结构、考试、成绩和逐题作答/得分录入 | 先保障数据正确性与历史版本 |
| 5 学情分析与 AI 辅助 | 基于真实记录的知识点分析、班级/个人建议，明确 AI 配置与隐私 | 不把生成建议当成事实，保留证据 |
| 6 个性化练习与完善 | 针对薄弱点的练习组卷、可解释推荐、质量和使用体验完善 | 由用户确定最终产品范围 |

各阶段持续遵守独立数据目录、旧系统隔离、本机端口、真实隐私保护与用户验收权约束。禁止把路线表理解为可连续推进六阶段的授权。

第三阶段最新补充：第五入口“化学知识图谱”，独立SQLite、二维交互网络和教师试做练习；不自动同步教材题库。仍待本阶段用户验收，不构成第四阶段授权。
