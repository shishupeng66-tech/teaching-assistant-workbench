# 第二阶段：项目所有者亲自验收清单

**第一阶段已获所有者验收。本次仅验收第二阶段；Codex 的工程自测不代替你的验收，也不代表第三阶段获准。**

建议先用你自己创建的“验收一班”“验收二班”和少量模拟学生体验。本系统默认没有固定演示学生，不要导入不必要的敏感信息。遇到问题请记录操作、预期、实际和截图，Codex 须先修复再交你复核。

## 一、启动、外观和隔离

- [ ] 若服务已运行，直接打开 http://127.0.0.1:5188；否则进入项目运行 ./scripts/start.sh。升级依赖先运行 ./scripts/setup.sh。
- [ ] 看到“教学辅助工作台”，侧栏仍只有四个业务模块，默认班级管理；版本为 0.2.0。
- [ ] 没有第一阶段固定演示班级/演示学生，也没有重新出现已删除的大标题和三块统计；班级切换和新建按钮仍紧凑。
- [ ] 浅色/深色、折叠导航及不同窗口宽度正常。题库、试卷库和 AI 仍是后续阶段占位。
- [ ] 设置显示本项目独立目录、SQLite 已连接、迁移 0002。没有使用 8086 或原系统数据。

## 二、班级创建、切换和修改

- [ ] 点击右上“新建班级”，侧边抽屉填写“验收一班”、学年、年级、编号并保存，成功后自动选择该班。
- [ ] 再创建“验收二班”，用顶部下拉切换两个班级。班名重复也能分别存在，并通过学年/编号/短 ID 区分。
- [ ] “班级设置”修改名称并保存，刷新仍保留；空名称无法保存。
- [ ] 添加学生后，顶部和名册显示真实班级人数；转班/归档后人数相应变化。

## 三、单个学生与查询

- [ ] 在教室下方点击“添加学生”，填写“验收甲”、可选学号、性别、入学年份和备注，保存后出现在名册。
- [ ] 再添加“验收乙”。允许新增同名学生，给出不同学号或留空，两个永久 ID 不同。
- [ ] 姓名必填；第一版非空学号在整个实例内唯一（包括归档学生），重复学号应明确报错，不覆盖原档案。
- [ ] 名册搜索按姓名/学号过滤；“学生管理”可搜索全部班级学生、完整内部 ID，并切换查看归档学生。

## 四、Excel 模板导入

- [ ] 当前班点击“Excel 导入”并下载模板；五列表头为姓名、学号、性别、入学年份、备注，模板不预填假学生。
- [ ] 在“学生导入”工作表填两条模拟记录，学号按文本填写，例如 X001、X002，保留前导零；保存 .xlsx。
- [ ] 选择文件并点“校验并预览”，能看到行号和有效记录。未点“确认导入”前，名册不会增加。
- [ ] 确认导入，看到新增人数，名册更新，刷新仍存在。
- [ ] 再预览/提交完全相同的文件，提示已导入，没有重复新增。
- [ ] 用新文件包含一条已存在学号、一条新学号，看到重复提示；默认整批拒绝，改为“跳过重复”后只新增新记录，已有学生不被覆盖。
- [ ] 用缺姓名、错误性别/年份或公式的文件预览，看到行号和错误，不能提交；修正后重新上传。
- [ ] 同名不同学号可分别导入；没有学号的修改版文件请人工核对，系统不会按姓名合并。

## 五、排座、交换、清空和布局

- [ ] 点击“安排座位”，配置例如 3 行 4 列。点击空座位，从“为选中座位选择学生”中选择验收甲。
- [ ] 给另一个座位分配验收乙，点击“保存座位布局”，看到成功提示。刷新后两人位置和行列不变。
- [ ] 再进入安排模式，将甲拖至乙的座位，看到两人交换，保存后刷新确认。
- [ ] 不用拖拽也可点击甲/乙的目标座位、选择另一位已排座学生来交换；操作应可靠。
- [ ] 点击一个已占用座位，选择“空座位（清空）”并保存，学生仍在名册、座位为空。
- [ ] 缩小行列时若仍有座位在范围外，保存应报错且原数据库布局不变；恢复原尺寸清空相应座位后才可缩小。
- [ ] 点“取消安排”不会保存草稿；安排未保存时页面明确说明需保存。
- [ ] 如需验证并发：打开同一班两个页面同时安排，先保存其中一个；另一页保存应提示版本冲突，不覆盖前者，点击“重新载入”后重新安排。

## 六、详情、编辑、转班和历史

- [ ] 普通浏览模式点击学生座位或名册姓名，进入学生详情，显示永久 ID、姓名、学号、性别、入学年份、备注、当前班级和座位。
- [ ] 点击“编辑资料”，抽屉修改姓名/备注并保存，刷新保持，永久 ID 不变。
- [ ] 在详情点击“转班”，选择验收二班并确认，永久 ID 不变，当前班级更新，当前座位为未安排。
- [ ] 返回原班，原座位自动为空；两班人数正确，归属历史保留旧班和新班及起止时间。
- [ ] 学生处于班级时修改班级学年、年级或编号，详情历史多一个段，旧学年不丢失，当前座位不变。
- [ ] 查看学生操作记录，可读到新增、修改、转班、座位变化等动作及变更前后信息。
- [ ] 历次考试、错题、知识点掌握、AI 分析、个性化练习只显示后续阶段占位，没有编造结论。

## 七、学生与班级归档

- [ ] 学生详情点击“归档学生”，不输入完整“确认归档”不能执行；确认后座位释放、当前归属结束，详情和历史仍保留且只读。
- [ ] “学生管理”勾选归档学生，可以找到该学生、查看历史；普通在档列表不再显示。
- [ ] 班级设置中归档验收班级，普通切换列表消失，勾选“查看已归档班级”能找到。
- [ ] 归档班级仍能查看学生和座位，不能新增、导入或排座；学生仍可从详情转出至在用班级。
- [ ] 理解本阶段归档为只读，不提供删除或取消归档。归档不等于清库。

## 八、刷新、重启、备份和恢复

建议在尚未输入正式业务数据时，用上述验收数据执行本节。恢复会回到选中时点，不只是恢复当前班。

- [ ] 刷新页面，班级、学生、历史与座位均保留；关闭再启动也保持，不重新生成随机布局。
- [ ] 设置页“创建备份”，看到真实副本和检查通过；目录中保留迁移前副本。
- [ ] 创建备份后修改一名模拟学生备注，确认修改已保存。
- [ ] 结束其他页面未保存编辑，在设置选刚才备份“恢复”，输入“恢复当前工作台”确认。
- [ ] 恢复成功，自动出现 before-restore 副本。刷新所有页面，学生备注回到备份时内容，座位与归属也对应备份时状态。
- [ ] 如需回到恢复前状态，恢复对应 before-restore 副本；较新的操作和数据仍保留在该副本。
- [ ] 不要把旧系统数据库放入新目录，也不要编辑所有权标识；系统只接受同实例受检文件。
