## 二维图谱实际功能

- 默认全局45节点、80条真实连线，箭头**前置知识→后续知识**。
- 强前置为蓝色实线，弱前置为灰色虚线；两类关系都可查看理由和审核状态。
- 拖动空白区域平移；滚轮或按钮缩放；“适应画布”显示网络；小地图可平移/缩放。
- 可拖动节点调整布局；节点位置、选择、局部/全局模式和视角保存在独立数据库，刷新及重启后保持。
- 按名称或原ID搜索，选择节点定位；点击节点用右侧抽屉查看名称、描述、掌握标准、前置/后续及对应4题。
- “局部关系”显示选中点与直接前置/后续，“全局图谱”恢复全网；不是按照上海六主题筛选。
- 审核、来源长说明、旧建议和迁移日志放数据管理，不占首页主要画布。

## 诊断题库实际功能

支持按知识点、难度、状态、题干/原编号筛选，后端返回分页结果（20题/页）。点击查看结构化题干、选项、答案、解析和本空间图片，以及原始来源字段和历史快照。

教师可以编辑题干、参考答案、解析和难度，公式/上下标/表格复用已有安全富文本组件，上传和加载图片使用独立API与独立assets，不能写入主库图片目录。保存采用expected_version防覆盖，编辑后重新待审核，保留版本。审核通过/拒绝均有记录。

**编辑后的题目不再套用旧source答案自动判分，改为教师对当前参考答案自评**，以免教师改了题干/答案但旧选项规则继续生效。原始来源选项与verify仅以转义文字保存，不执行；48张来源SVG沿用已安全转成的PNG，没有重新注入SVG或来源网站。

## 独立知识诊断的范围及局限

已阅读固定commit下[diagnose/engine.js](https://github.com/xiaoyang111222/cn-math-taxonomy/blob/aa2c22058222d0df404f1819e2fbdb97a62049ea/diagnose/engine.js)的选题与先修回溯规则，只在本项目重实现必要的保守子集，未执行或嵌入来源网站：

1. 教师主动选择1个目标知识点，确认了解资源/判分局限，再开始2/6/12/20题上限的试做。
2. 每个知识点先出standard题；首题对则优先challenge，首题错则补basic，每个点最多2题。
3. 两题都对标“本次两题通过”；一对一错标“本次表现不稳”；两题都错只标“可能薄弱”，不是正式掌握度。
4. 两题错误后，最多回溯2个直接先修，hard优先于soft；重复节点不重复排队，总题量不超过设置上限。未测点保持未知，不像上游完整引擎那样推断所有祖先已掌握。
5. 原choice题只比较字母；原numeric题用受控Fraction做数值等价比较，不接受可执行表达式，单位按题干填写。编辑过的题仅教师自评。
6. 提交后显示上一题答案、解析和比较方式；保留完整作答、使用的题目版本快照、进度及本次结果。重复提交旧步数不会计分，刷新/重启可继续或查看记录。

这是教师检查资源及自用练习，不是正式学生诊断。上游题目和先修关系未经过全面教师验证；数值/字母相同不代表真实理解，答错也可能是题目问题、输入或偶然失误。没有真实学生档案、成绩、画像或AI调用；本次结果不会写入班级管理或学生长期掌握度。不能把“可能薄弱”当作教学定论。
