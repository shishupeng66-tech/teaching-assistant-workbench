# 第三阶段用户亲自验收清单

第一、二阶段已获所有者验收；本清单仅用于第三阶段。Codex 自测不代表用户验收。所有测试建议先用自己创建的“验收化学 / 自建验证版”和模拟题目，不导入不必要的学生信息。

## 1. 打开与已有功能

- [ ] 打开 http://127.0.0.1:5188，确认版本0.3.0，班级、学生、座位及历史仍在。
- [ ] 左侧仍只有班级管理、题库、试卷库、AI辅助。试卷、考试与AI未开放。
- [ ] 主题、导航折叠、页面刷新正常；设置中 SQLite 已连接、迁移0003。
- [ ] 本实例没有混入 Codex 的模拟题库或未经核实的出版社教材目录。

## 2. 建立自己的教材目录

- [ ] 题库 → 教材目录管理 → 新增学科，例如“验收化学”、编码CHEM-ACCEPT。
- [ ] 新增教材版本，例如“教师自建验证版”；选择版本后新增册别，填九年级、上册。
- [ ] 新增目录节点“第一章”，层级章；选中后再新增“第一课时”，层级课时，父级选第一章。无需强制建立节。
- [ ] 再新增同级节点，展开/收起目录树，使用上下箭头调整排序；刷新后顺序保留。
- [ ] 编辑根节点名称时父级仍为空，保存不形成自循环；尝试把父节点放到自己的下级，应明确拒绝。
- [ ] 修改目录教学目标/说明后保存，题库章节详情展开“教学目标与章节说明”可看到。
- [ ] 新建第二个教材版本与册别，可拥有不同目录结构。停用后保留原有记录，没有物理删除入口。

## 3. 知识点主库与多教材映射

- [ ] 进入知识点主库，选择验收学科，新增“元素组成”、编码C9-001、说明，并由教师确认保存。
- [ ] 再新增“化学式”，设置上级、前置或相关知识点；Command多选可选多个，循环前置/父级会报错。
- [ ] 在知识点编辑抽屉勾选两个教材版本的目录节点，同一知识点有多个教材映射，永久ID不变。
- [ ] 搜索知识点名称、编码或说明能找到；停用后可用“包含停用知识点”查看。
- [ ] 在题库选择章节，调整知识点关联；解除某章映射后另一教材映射及题目关联不丢失。
- [ ] 不存在可自动把AI建议写入正式主库的入口；本阶段只由教师核实保存。

## 4. 录入第一道化学题

- [ ] 题库顶部选学科、版本和册别，点击章节，再点新增题目。
- [ ] 填适用年级，选择题型和难度，录入题干、标准答案、解析与可选来源。单/多选题可将选项写成题干列表。
- [ ] 使用下标/上标写SO₄²⁻；用“公式 / 化学式”插入 `\ce{2H2 + O2 -> 2H2O}` 和 `\ce{SO4^2-}`，预览箭头、电荷及上下标正确。
- [ ] 插入表格，填写内容；上传一张本地PNG/JPEG/WebP图片，确认预览出现。
- [ ] 关联至少两个知识点，选择一个主要知识点；可填写权重。按需建立小问编码、预留满分和评分依据，并在知识点关联中填写涉及小问编码。
- [ ] 勾选不同教材版本的两个章节，保存草稿，获得一个永久题目ID而不是两道复制题。
- [ ] 刷新详情，题干、公式、图片、答案、解析、知识点和章节引用均保持。

## 5. 题型、审核和历史

- [ ] 分别体验单选、多选、判断、填空、简答、计算、实验、综合八种题型。
- [ ] 新题和Excel导入题均为草稿；没有标准答案不能提交审核。
- [ ] 提交审核 → 待审核 → 点击审核通过、明确勾选教师确认 → 已审核。
- [ ] 待审核题可填写原因退回草稿。审核记录包含操作、状态、备注与时间。
- [ ] 编辑已审核题后保存，状态退回草稿，旧审核/内容快照保留；切换历史版本看到旧内容和图片。
- [ ] 归档后只读，全部状态或已归档筛选中可找到，不删除旧版本。
- [ ] 试卷、正式考试、成绩及AI分析没有被提前实现。

## 6. 相似题、章节复用与范围统计

- [ ] 录入与已有题标准化后相似的题干，系统提示相似题；未明确核对确认时不保存。
- [ ] 核对后可以保留独立题目ID，或取消操作；系统不自动合并。
- [ ] 章节中点击“关联已有题目”，把另一道题关联进来；重复操作不增加重复关系或重复计数。
- [ ] 同一题关联父章和子课时，切换“仅当前节点 / 包含全部下级章节”，汇总不会把同题重复计数。
- [ ] 教材目录改名、换父级或排序后，题目知识点仍保持；详情能查看被哪些章节引用。
- [ ] 检查题目总数、已审核数、题型/难度/学科数量和知识点覆盖，与手动创建的数据一致。
- [ ] 年级、题型、难度、知识点、审核状态筛选有效；统计随同一范围和筛选计算。
- [ ] 用“全部题目”或全局搜索跨教材检索；有超过一页时切页，每页数量可改，列表由后端分页。

## 7. 题目Excel导入

- [ ] 题库 → 批量导入 → 下载模板，保留“题目导入”工作表和12列表头。
- [ ] 填题型、题干、标准答案、解析、1–5整数难度、可选来源；学科可填现有名称/编码或留空用页面所选学科。
- [ ] 若按章节关联，同时填写教材版本、年级、册别、章节路径；多路径及多知识点编码用 `|` 分隔。
- [ ] 路径用 `/` 分隔，目标节点须已存在且唯一；未知或歧义路径显示行号和错误，不能静默新建或猜测。
- [ ] 点击校验并预览，尚未确认时数据库题量不增加；错误行必须修正后重新上传。
- [ ] 重复可整批拒绝、跳过，或逐项核对后保留独立题目；不覆盖原题。
- [ ] 确认批量保存后题目为草稿，需教师逐题审核；相同文件重复提交不会重复新增。
- [ ] 普通文本可用 `$...$` 包裹LaTeX/mhchem。Excel嵌入图片、宏、外链、Excel公式不接受；图片请导入后在编辑器上传。

## 8. 教材目录结构化导入

- [ ] 教材目录管理选择目标册别 → 批量导入目录 → 下载模板。
- [ ] 填章节路径、层级（章/节/课时）、排序、说明；新父路径必须已有或在同文件列出。
- [ ] 先预览；缺父路径、歧义、非法层级或排序有明确错误。已有路径不覆盖，可选择跳过。
- [ ] 未输入“目录已审核”不能提交；教师核实后输入确认文字保存，树形结构、顺序、说明正确。
- [ ] 目录不是系统擅自补全的出版社目录。

## 9. 重启与完整备份恢复

仅用上述验收数据测试，恢复是整个实例回到某个时点，不仅当前章节。

- [ ] 刷新及关闭重启后，原班级/学生、目录、知识点、题目、审核、历史及图片保持。
- [ ] 设置中创建备份，显示检查通过及图片数量；备份目录有 `.sqlite3` 和同名 `.sqlite3.assets` 文件夹。
- [ ] 理解两者须成对保管，不能只复制数据库文件就宣称已保存题目图片。
- [ ] 创建备份后修改模拟题，再恢复刚才备份：输入“恢复当前工作台”，系统先生成恢复前副本。
- [ ] 刷新全部页面，检查原题内容、目录、知识点、版本、审核和图片回到备份时点。
- [ ] 需要回退此次恢复时可恢复 before-restore 副本。不要向新目录放入其他项目的数据库，不修改所有权标识。

## 10. 布局、边界与反馈

- [ ] Mac常用桌面和较窄窗口检查目录树、题目列表、编辑器、表格、抽屉，深色文字清晰，无整页横向溢出。
- [ ] 章节说明及后续教学工具可展开；后续组卷、章节测试、AI建议按钮均禁用。
- [ ] Word/PDF/OCR/AI识别没有显示为可用，系统没有虚构学情。
- [ ] 如有问题，反馈页面、步骤、预期、实际及截图，先修复再由你重新验证。
