# 第一阶段用户亲自验收清单

**本清单由项目所有者亲自执行。Codex 自测通过不代表你已验收。** 可在各项后记录实际现象；遇到问题请反馈所在页面、操作、预期和实际结果。

## 1. 启动与隔离

- [ ] 终端进入项目目录，运行 `./scripts/start.sh`；首次安装依赖需要网络。
- [ ] 看到“教学辅助工作台已就绪”，前端是 http://127.0.0.1:5188，健康地址端口为 8087。
- [ ] 浏览器打开前端，页面产品名为“教学辅助工作台”，默认进入班级管理，上方显示本地服务已连接。
- [ ] 原有 SmartKBS 仍按原方式运行，原有文件和数据没有被迁移或改动。无需在旧系统中输入或修改数据来验收。

## 2. 主界面和座位图

- [ ] 左侧业务导航只有“班级管理、题库、试卷库、AI 辅助”，底部单独为系统设置。
- [ ] 班级页显示“七年级（1）班”和“演示数据”，12 名演示学生、24 个座位、12 个空位，黑板、讲台和座位清晰。
- [ ] 演示学生只有“演示01”等模拟称呼，没有真实学生个人信息。
- [ ] 新建班级、切换班级、座位详情均不可操作，提示后续阶段开发；不会打开虚假的业务编辑页。
- [ ] 点击左上折叠按钮，导航缩成图标，再点击可展开；折叠后图标仍可导航。

## 3. 其他三页

- [ ] 点击“题库”：看到搜索框、学科/题型筛选和列表空状态，输入及业务按钮禁用。
- [ ] 点击“试卷库”：看到试卷区域和禁用的新建试卷按钮，没有真实试卷业务。
- [ ] 点击“AI 辅助”：看到班级分析、学生个人分析、个性化试卷三个占位区，并明确未接入 AI，没有虚构成绩或正式学情结论。
- [ ] 各页面刷新后仍能正确显示；浏览器前进、后退可回到对应页面。

## 4. 外观与窗口

- [ ] 默认浅色；点击右上月亮切成深色，再切回浅色，文字清晰。
- [ ] 切换深色后刷新页面，主题保持；进入设置也可切换。
- [ ] 在常用 Mac 桌面窗口、较窄窗口分别查看各页，没有内容互相遮盖或横向溢出；窄屏会自动缩为图标导航，座位可调整列数。

## 5. 本地设置与真实备份

- [ ] 打开“系统设置”，核对系统名称、v0.1.0、SQLite 已连接和目录信息。
- [ ] 数据和备份是新的 TeachingAssistantWorkbench 用户级目录或你明确配置的独立目录，不能是旧系统路径。
- [ ] 点击“创建备份”，看到成功提示及一条“检查通过”的备份文件，文件大小大于 0。
- [ ] 可用 Finder「前往文件夹」打开设置显示的备份目录，确认独立 `.sqlite3` 文件真实存在；不要手动修改文件或标识。

## 6. 恢复保护和最小恢复能力

请仅在本第一阶段的新实例上验证；第一阶段没有实际学生数据。不要把旧库放进新目录，也不要指向旧库目录。

- [ ] 点击刚创建备份的“恢复”，出现确认对话框，说明会替换当前实例数据库，且先创建恢复前副本。
- [ ] 不输入或输入错误文字，“确认恢复”不能点击；点“取消”后不恢复，备份列表不新增副本。
- [ ] 再点恢复，完整输入“恢复当前工作台”，点击“确认恢复”。看到恢复完成，并新增 `before-restore-...sqlite3` 副本。
- [ ] 数据库仍显示已连接，刷新/重新启动也正常。
- [ ] 理解本阶段座位是前端演示，不随恢复变化；Codex 的隔离测试已验证过测试数据库实际值的恢复，不需要你编辑 SQL 来验收。

## 7. 停止与再次启动

- [ ] 在原启动终端按 Control+C，看到关闭提示；本次前后端关闭，其他项目仍运行。
- [ ] 再运行 `./scripts/start.sh`，启动正常；设置中的备份列表仍然存在，系统没有重置数据。
- [ ] 若端口被占用，脚本明确报错，不擅自关闭其他进程。无需为了验收主动占用端口。
