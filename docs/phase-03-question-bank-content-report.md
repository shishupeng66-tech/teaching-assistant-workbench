题库默认“全部内容”，支持“已审核”“待审核”切换；保留全局检索、后端分页和原筛选。知识点用抽屉展示定义、教学要求、掌握标准、来源及审核记录；题目列表可直接展开题干/答案/解析，详情页显示待确认教材引用。统计改为紧凑摘要，分布折叠。

新增入口“题库→集中审核”（/questions/review），可按主题/专题/课题及下级筛选、单选或全选。预览显示范围、项目数量、内容及本批候选关联，然后教师明确确认才提交。知识点须先或同批通过，才可批准相关题目。退回须写原因；题目回草稿，知识点为已退回，编辑后可重新提交。已有版本和审核记录保留。

预览保存版本与内容指纹；版本过期、重复提交、非法状态或失败均拒绝并回滚。批准只处理本批范围内关联，不顺便批准其他专题复习关联。修改种子知识点回待审核，修改题目回草稿。未实现正式考试资源选择器，因为试卷库仍未授权；待审核绝不会自动标成已审核。
