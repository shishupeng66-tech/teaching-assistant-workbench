## 4. 集中审核：先小范围操作

审核会真实改变教材资源状态，请在看完内容后自行决定是否批准。

1. 在一个课题点击“集中审核”。顶部范围应是该课题，含下级。
2. 查看知识点定义、教学要求和掌握标准，展开题目看选项、答案和解析。
3. 先选择你认可的知识点及其题目。题目批准需关联知识点已审核或同批批准。
4. 点击“预览批量批准”。核对范围、知识点数、题目数和每项候选关联；此时尚未批准。
5. 如内容和关联都正确，点击“确认本批审核”。应有成功提示并留下审核记录；范围外复习关联不会顺带批准。
6. 返回课题，切换“已审核”，应看到刚才批准的内容，统计相应变化。
7. 对另一条有问题的内容，仅勾选该条，填写原因，点击“预览退回”，核对后确认。题目变草稿、知识点变已退回，不物理删除历史。
8. 在“全部状态与审核记录”“退回/编辑后题目草稿”或“已退回知识点”中找到内容。修改知识点后回待审核；修改题目保存草稿后去详情“提交审核”，再重新集中审核。
9. 再查看审核记录，应看到批准/退回原因与时间；预览后若内容被修改，旧预览应拒绝提交，需重新预览。

不要为了检查功能而未阅读就批准全部192题。若不想改变正式资源状态，可以只看预览并取消。
