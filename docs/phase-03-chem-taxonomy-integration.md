## 数据模型与可追溯性

Alembic增量迁移`0004_taxonomy`：

- knowledge_points新增review_status，已有知识点默认approved，本次新增点为pending；原有知识点ID、内容和关联不变。
- taxonomy_sources：来源仓库、固定commit、署名、许可证、原文件SHA256、图像哈希、转换说明和导入哈希。
- taxonomy_items：point/question/dependency三种记录，保留原ID、原名称、完整原payload、本地知识点/题目/前置点UUID、处理及审核状态；源版本通过source_id关联。共305条来源记录。
