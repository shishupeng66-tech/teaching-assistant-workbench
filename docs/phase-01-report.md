## 1. 实际完成内容

- 在事先检查为空的工作目录下，全新创建 teaching-assistant-workbench；没有覆盖不明文件。
- 初始化本地 Git，配置忽略依赖、虚拟环境、数据库、备份、日志、测试产物与 .env；未建立远程仓库、未推送。
- 独立 frontend、backend、data 说明、docs、scripts、tests 目录；前端页面和通用组件分开组织，后端区分 API、核心配置、存储服务和迁移。
- FastAPI 健康检查、数据库状态、Pydantic 环境配置、SQLAlchemy 连接、Alembic 0001 迁移、中文 JSON 错误和请求日志。
- 当前只建系统归属表和迁移版本表，未创建实际学生、题目、试卷、考试等业务表。
- 默认使用源码之外的用户级数据与备份目录，允许用两个环境变量覆盖；没有访问或迁移旧库。

### 界面框架

- 产品名称统一为“教学辅助工作台”。浅色为默认，白色/浅灰色为主、蓝色强调；支持深色与浏览器主题记忆。
- 左侧业务导航严格四项，底部系统设置，顶部导航可折叠；小窗口自动使用图标导航。
- 班级管理为默认页，显示班级切换占位、班级名、黑板、讲台及 React 座位组件。
- 24 个座位中展示 12 名“演示01”等模拟学生，明确标注演示，不含真实个人信息，不写入数据库。座位详情、班级切换与新建班级禁用。
- 题库页具有搜索、学科/题型筛选和列表空状态占位；试卷库有列表区与禁用的新建按钮。
- AI 页有班级分析、学生个人分析、个性化试卷三个占位区，明确未接入 AI，不显示虚构正式学情结论。
- 页面路由可直接打开和刷新，未知路由显示返回班级管理的入口。

### 设置与备份恢复

- 展示系统名称、版本、主题、真实本地目录、SQLite 连接及迁移状态。
- “创建备份”实际生成独立 SQLite 副本，并验证完整性、项目、实例及版本；显示文件大小、时间和可用状态。
- 恢复对话框须完整输入“恢复当前工作台”；服务端再次校验确认文字。
- 只恢复本实例、受控备份目录下的有效文件，拒绝跨实例、损坏文件、路径穿越和符号链接。
- 恢复前自动创建 before-restore 副本，校验临时副本后原子替换当前已确认归属的数据库。
- 系统与目录所有权标识、进程排他文件锁、本机请求头和来源/Host 检查，降低误操作及网页跨来源写请求风险。

### 开发体验与文档

- ./scripts/start.sh 提供统一启动，首次缺少依赖时自动调用 setup.sh；uv 可用时使用 frozen 锁文件，否则使用 venv + 固定 requirements。
- 仅绑定 127.0.0.1:8087 与 127.0.0.1:5188，不使用 8086。端口被占用明确退出，不停止其他服务。
- Control+C 统一关闭本次创建的服务；服务异常退出时清理同次启动的另一服务；不会清库或重置数据。
- README、AGENTS.md、.env.example、架构文档、六阶段路线、阶段报告和用户验收清单全部提供中文说明。
- AGENTS.md 明确用户最终验收权、逐阶段停止条件、后续授权门槛及长期隔离规则。

## 6. 已知问题与风险

1. **开发依赖安全告警尚未解决。** 完整 npm audit 报告 picomatch 的高危 ReDoS：[GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)，向 fdir、tinyglobby、Vite、React Vite 插件传播，共 5 个依赖条目。检查时 registry 最新 picomatch 为 4.0.7，修复候选 4.0.8 不存在；没有保留不存在版本的覆盖配置。audit 建议强制降级 Vite 至 6.2.7 属跨主版本回退，未采用未经完整评估的回退来掩盖告警。开发服务仅本机访问，不接受业务输入作为 glob；这缩小暴露面，但不代表漏洞已修复。需在后续维护中复核上游修复并重测。生产依赖 audit 报告为 0，不代表系统绝对安全。
2. 备份只存本机，尚无加密、异地副本、计划备份、自动清理或跨实例导入；不能抵御整机磁盘损坏。标识丢失/损坏时会安全拒绝，第一阶段不提供强行领用未知数据库功能。
3. 恢复目前只针对本实例和迁移 0001，后续新增业务表与迁移时必须完善兼容策略。第一阶段没有业务数据，界面演示不随数据库恢复而改变。
4. 开发服务没有正式多用户身份鉴权，不应暴露到局域网或公网。系统不是生产部署方案。
5. 自动浏览器验证使用 Chromium，另用 Tabbit 查看；尚未独立完成 Safari/Firefox 引擎验证。Mac 常见桌面和窄屏已做基础检查，用户仍需用实际浏览器体验。
6. 首次安装依赖需要网络；E2E 浏览器安装也可能需要网络。主题偏好属于当前浏览器，不跨浏览器同步。
