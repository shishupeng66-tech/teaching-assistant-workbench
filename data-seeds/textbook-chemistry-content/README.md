# 上海六主题教材题库：原创内容种子 v1

64个细分知识点、192道原创练习，每个知识点3道；全部待教师审核。**不是官方题库，不是教材原文，也不是独立化学图谱的复制或同步。**

- `catalog-snapshot.json`：从当前正式数据库读取的65节点永久ID、名称、父子关系、顺序与说明。保留六主题十专题；未新建目录。
- `authoring.py`：逐项编写的定义、教学要求、掌握标准和原创问题。编制用的课题别名由build显式对应真实目录名称。
- `build.py`：生成稳定UUID、候选关联、专题复习复用和选择题选项重排，不访问数据库。可重复编制，输出字节一致。
- `content.json`：实际导入文件，含原始来源、审核状态和每条关联；版本键`shanghai-textbook-original-v1`。

题目难度1—3，包含单选、简答、计算、实验和综合，不为了凑题型机械生成。同一知识点的三题用于基础辨析、应用或证据解释。10个专题复习复用本专题内容；两处附录只映射相关实验/信息查读能力，不代表完整附录内容已核实。

课程范围参考教育部2022版课程标准发布资料及高教社课标解读的五学习主题，具体链接及访问限制见content.json.sources。教材对应来自本系统已存在目录，未取得整套教材正文及逐课教学用书的权威核对，因此**全部映射是教师待确认建议**。这些定义与题目为原创教学草案，不将课题标题当作知识点，不复制商业题库全文。

独立校验器`backend/app/services/textbook_validation.py`使用受控公式解析、原子守恒、Fraction比例计算等检查37项数据，其中10项配平方程式；核对实际答案文本、单选字母与选项顺序、完整性及精确重复。校验不是教师审题，不能保证教学完备性。

停止本项目后端后，在项目根目录运行：

```bash
backend/.venv/bin/python scripts/seed_textbook_content.py
backend/.venv/bin/python scripts/seed_textbook_content.py --apply
```

第一条只预览内容（若数据库版本较旧，Storage仍会先备份并执行必要迁移）；第二条在首次写入前备份主数据库和附件，事务导入。数据库实例归属和文件锁沿用系统保护。同版本文件哈希改变则拒绝覆盖；重复执行不更新教师修改、审核结果或关联。**不要清空数据库来重新导入。** 目录身份变化时停止并要求重新评估映射。

正式关系与候选关系分开：导入后536条候选关系（知识点134、题目402），正式章节关系不自动增加；页面默认可预览候选。教师在“题库→集中审核”指定范围、预览后批准，才写入正式关系及审核记录。
