# 上海五四学制初中化学教材目录种子 v1

本数据仅包含教学导航目录及必要元数据，不含教材正文或扫描件。

- grade8.json：2024年8月第1版，八年级全一册，38节点。
- grade9.json：2025年8月第1版，九年级全一册，27节点。**不是已核实的2026秋印次**。
- sources.json：所有已检查来源、适用范围及差异。出版社原件与学校实际用书尚待人工核对。版权页信息来自第三方上传教材的文字转录，不声称官方认证。

数据中的主题、专题、课题、跨学科实践、复习、附录保留语义类型。现有系统的通用树已能表示这些父子关系，存储适配为 chapter/section/lesson，语义类型同时写入节点说明，结构化文件保留原始类型、编号、页码、排序、来源及核实状态。没有新增/重建表，也没有修改0003迁移。

只导入主目录页明确列出的节点；不把课文内部标题或附录内部标题扩为目录。目录排版空白和跨行换行已合并，保留编号、名称和中文标点。知识点和题目均不自动生成。

## 执行

在项目根目录，先校验（不连接数据库）：

```sh
backend/.venv/bin/python scripts/import_shanghai_chemistry.py
```

实际导入：先在本项目服务终端按 Control+C；保持环境变量与启动服务一致，再执行：

```sh
backend/.venv/bin/python scripts/import_shanghai_chemistry.py --apply
./scripts/start.sh
```

默认使用用户级工作台数据目录，支持 TAW_DATA_DIR / TAW_BACKUP_DIR。独占锁会拒绝与运行中的后端同时使用数据库。每次实际导入先创建并验证数据库及附件完整备份，随后单事务新增两版本、两册和目录及审计。已有“化学”学科无歧义时复用且不修改，其他同名不同身份的目标实体报错，禁止覆盖。

稳定UUID由本种子命名空间和节点key派生；导入批次记录内容SHA256。重复执行核对已存字段，新增0节点；人工修改过已导入目录后再执行会拒绝覆盖，保留教师修改。需要变更种子时应人工复核并设计新版本迁移，不直接改文件后强行重导。失败事务回滚本批数据库写入，已验证的安全备份仍保留。

恢复须在系统设置按原流程明确确认，数据库.sqlite3和同名.sqlite3.assets目录必须共同保留。不要在已有新教学数据后仅为重导目录而恢复旧备份。
