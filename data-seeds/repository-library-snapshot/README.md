# 当前正式教材题库的只读资料快照

2026-11-19经项目所有者授权，为首次上传GitHub而从本项目主库只读事务导出。不是SQLite数据库备份，不包含班级、学生、座位、全局审计、密钥或其他业务表。

- snapshot.json：白名单教材表，保留当前“初中化学”六主题、65目录节点、64知识点、192题、永久ID、答案解析、修改版本、教学要求、掌握标准和候选关联状态。JSON类型列保留SQLite原始JSON文本，需由对应模型解析。

- 原创编制文件另见../textbook-chemistry-content/，教材来源见../textbooks/shanghai-junior-chemistry/。独立图谱来源在../cn-math-taxonomy/，不混入此快照。
- 当前正式教材题目没有图片附件；独立图谱48张图片已单独随其来源目录保存。若未来出现正式附件，应导出经过审核的引用文件和哈希，不能仅提交附件数据库记录。

本快照用于追溯现有资料；不是可覆盖正式库的恢复文件，没有自动执行入口。禁止把JSON直接灌入已有正式数据库。首次初始化使用项目既有导入脚本并在独立目录验证，操作顺序见docs/github-repository.md。所有待审核状态保持原样；不要将这些原创练习声称为已经教师审核的官方试题。
